## 📌 Sobre o Projeto

O **A.T.L.A.S.** é um assistente robótico didático e interativo (busto humanoide) concebido para apoiar as rotinas operacionais e pedagógicas do **Espaço 4.0**. O projeto combina manufatura digital, eletrônica dedicada, Internet das Coisas (IoT) e Inteligência Artificial para servir como ferramenta de ensino prático baseado em problemas (**PBL**).

---

## 🛠️ Tecnologias e Recursos Utilizados

* **Manufatura Digital:** Impressão 3D (PETG/PLA) e Corte a Laser em Acrílico.
* **Eletrônica:** Placa de Controle Customizada (**Proton 1S**), Servomotores SG90/MG996R, Sensores Ultrassônicos (HC-SR04).
* **Processamento e Computação:** Raspberry Pi / Arduino.
* **Linguagens de Programação:** Python (IA, Visão Computacional, Áudio) e C++ (Firmware de Controle).
